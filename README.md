# AxolotlSDK

Minecraft Client Version API SDK is a developer tool designed to fetch metadata and download Minecraft client versions. It provides a unified wrapper around the official and third-party APIs, allowing you to seamlessly access and download versions for vanilla Minecraft as well as all major mod loaders: Forge, Fabric, Quilt, and NeoForge.

### Supported Loaders

| Loader | Supported |
| :--- |:-----:|
| Vanilla (Piston) | ✅ |
| Forge | ❌ |
| Fabric | ❌ |
| Quilt | ❌ |
| NeoForge | ❌ |
